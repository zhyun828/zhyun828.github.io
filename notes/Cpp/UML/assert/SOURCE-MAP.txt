在仓库根目录使用自行安装的 PlantUML jar 再生成：
java -jar <plantuml.jar路径> -charset UTF-8 -tsvg docs/notes/Cpp/UML/assert/*.puml
java -jar <plantuml.jar路径> -charset UTF-8 -tpng docs/notes/Cpp/UML/assert/*.puml
编辑手工 SVG 后用 SVG 渲染工具导出同名 PNG。
